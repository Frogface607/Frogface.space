> Источник: глубинное голосовое интервью Босса (`Голосовое-интервью-frogface.space.md`, 3303 строки, 12 блоков). Edison Bar закрыт 31 мая.
> Это **источник истины**. Всё прошлое — устарело там, где конфликтует.

## 0. Одной фразой

**frogface.space — личное пространство предпринимателя, который пытается вырваться из болота. Его легенда.**

Не сайт, не портфолио, не демо AI. **Point-and-click квест-прогулка по легенде Сергея Орлова / Frogface.** Ядро — история. Лягуха, болото, здания, карта — залипательная оболочка.

---

## 1. Что НЕ потерять (ядро)

> «Лягухи — оболочка. Самое важное — моя история.» — Босс

Даже если убрать карту, анимации, квест — должно остаться: **путь Сергея, ошибки, проекты, опыт, свобода, движение из болота к небоскрёбу.**

Главная цель сайта (по приоритету):
1. Рассказать историю (она нестандартная — Босс очень хочет её рассказать)
2. Дать гостю залипнуть → «вау, как интересно, хочу исследовать голову этого человека»
3. Конвертировать в клиента Studio / часть вселенной
4. Дать Боссу витрину прогресса + стимул обновлять

## 2. Формат — POINT-AND-CLICK КВЕСТ (зацементировано)

Метались между изометрией / single-scene / landing / game. **Финал — классический 2D point-and-click квест-прогулка** (Босс: «механика придумана 30 лет назад, всё сильно проще»).

```
ГЛАВНЫЙ ЭКРАН (hero)
  Frogface сидит на лавочке у болота, вид сзади/3-4, смотрит на закат+Башню
  Текст в небе (манифест) + меню сверху + кнопка «В ПУТЬ»
        ↓ клик «В ПУТЬ» → Frogface встаёт →
КАРТА БОЛОТА (навигационный хаб)
  Здания-проекты + Башня на горизонте ($0/$10K) + туман войны по краям
        ↓ клик на здание →
ЛОКАЦИЯ (2D side-view сцена)
  Frogface ходит слева-направо, подходит к объектам по клику
  Объекты открывают: истории, кейсы, галереи, пасхалки, ссылки
```

**Не open world. Не изометрия.** Набор красивых интерактивных 2D-сцен, которые наращиваются модульно.

### Поведение Frogface
- Главный экран: сидит, смотрит вдаль (idle-анимация — дыхание/моргание/глоток кофе)
- «В путь» → встаёт → карта
- В локации: ходит слева-направо, подходит к объектам
- НЕ полностью свободный игрок — авторский персонаж, делает что соответствует сцене
- **Тап по Frogface = now-статус** (что делаю сейчас, где, над чем работаю)
- Без симуляции дня/ночи/настроения — живёт в одной выбранной сцене

### Технический подход к «ходьбе» (важно — риск-митигация)
Walk-cycle через Higgsfield плыл лицом. Решение для MVP:
- **Один консистентный спрайт Frogface** + idle-анимация из ОДНОГО кадра через Seedance (лицо не плывёт)
- «Ходьба» = перемещение спрайта к точке клика + лёгкий bob/bounce, БЕЗ 24-кадрового цикла
- Полноценная walk-анимация — позже, не блокер MVP

## 3. Главный кадр (дословно из интервью)

- Камера: вид **сзади / слегка сбоку / 3-4**
- Frogface сидит **слева внизу** на лавочке / у кромки болота
- Смотрит вдаль **мечтательно**, в руке может быть стаканчик кофе
- Вокруг — **город на болоте**, видны здания-проекты
- Жизнь течёт: NPC ходят, мягкая анимация (вода, свет, огни)
- Свет: **закат → переходит в вечернее небо со звёздами** (градиент)
- На горизонте — **силуэты небоскрёбов / Башня**
- Сверху — меню/навигация
- Текст в небе (манифест): *«Личное пространство предпринимателя, который пытается вырваться из болота. Делаю своё, настоящее.»*
- CTA: **«В ПУТЬ»**

---

## 4. Башня — $0 / $10,000 MRR (сердце концепции)

На горизонте стоит небоскрёб — **главная заблокированная цель**.

```
SKY CONDO / Башня — LOCKED
Прогресс: $0 / $10,000 MRR
Условие: стабильные $10K/мес
Смысл: свобода, аренда крутого кондо (Бкк и др.), путешествия,
       жизнь без привязки к месту
```

Чекпоинты: $5K (выживание закончено) → $7K (комфорт) → $10K (Башня открывается). Прогресс **Босс ведёт вручную**. Это публичный прогресс-бар его жизни — даёт гостю эмоцию «пройду путь вместе с ним».

Цитата в канон: *«Я не хочу мечтать о том, чтобы выжить. Я хочу мечтать о квартире в небоскрёбе с окнами в пол.»*

## 5. Локации MVP (3 + Башня)

### 5.1 Хижина (готова, переиспользуем `interior/hut.png`)
Дом Frogface. Бедно/просто, но НЕ бомжара — со вкусом, креативно.
- Ноутбук, кружка с логотипом Frogface (НЕ «No Funds» — заменить на лого), оранжевая лавовая лампа (задаёт свет), постеры (музыкальные/лягушачьи), окно с видом на небоскрёбы, лёгкий неон, пасхалки (бонг у кровати — для угара)
- Объекты: Frogface за ноутом → **now-статус** + **биография** (это «один час» Босса — главный приоритет контента); постеры → галерея; окно → Башня/цель

### 5.2 Edison Bar (готова `interior/bar.png`, но переделать под реальный Edison)
**Не абстрактный бар — настоящий Edison, перенесён во вселенную лягух.** Босс даст фото-референсы (кирпичи, стойка, сцена).
- История 9.5 лет, тысячи концертов, рейтинг 4.9 (аномально высокий — соц-доказательство), афиши, джаз/рок/фристайлы
- Автоматизации, которые Босс делал для Edison (главный доказательный кейс — Edison Toolkit)
- Отзывы людей (собрать от партнёров/музыкантов/шефов — TODO Боссу)
- Сцена: музыкальное творчество, видео, песни
- **Главный месседж: «я не теоретик, я реально строил мир»**

### 5.3 Studio (лендинг ГОТОВ — Босс: «имба»)
- Кнопка в верхнем меню (прямой вход для B2B) **+** отдельное здание на карте
- Сохранить: дорогой B2B-вид, пошаговость процесса, «профессионально но с душой»
- Brief-форма начинается с боли: **«Расскажи, что тебя заебало больше всего»** + чекбоксы решений + компания/город/сфера/контакт → дальше Босс/AI делает ресёрч компании и даёт персональный ответ
- **Калькулятор стоимости** (вместо жёстких пакетов $3K/$5K/$10K — подать мягче, рыночные диапазоны 2026). TODO: отдельное исследование цен.
- **EN-версию заложить** (международность)

## 6. Будущие здания (заблокированы / teaser в MVP)

Появляются вручную по мере роста («я расту — растёт мир»). Туман войны вокруг карты.
- **Receptor** — отдельное серьёзное здание-корпорация (AI для HoReCa, техкарты, меню). НЕ прятать в баре.
- **Магазин** — мерч/одежда, история бренда «Метка»/Evidence, дизайны футболок, дропы
- **Нечто / бургерная** — UFO-бургеры, классный старт → ошибки → заморозка → может вернётся
- **Кладбище факапов / Школа ошибок** — честно про ошибки, не героизировать. Сильная локация (Босс загорелся)
- **Спортзал** — трекинг тренировок, публичная дисциплина
- **Студия звукозаписи** — музыка/фристайл (если вернётся)
- **Лаборатория** — песочница AI-экспериментов
- **Зона «Посадят»** — ироничная/юр-страхи
- **Небоскрёб / Башня** — главная цель (см. §4)
- **Автосалон** — заблокирован (нет машины, но хочется)
- **NPC** — Wizzle с книгой и др., населяют мир позже

### Механика-канон: «Клиент = здание»
Каждый клиентский проект → новое здание на карте, клиент становится частью вселенной Frogface. Портфолио = живой растущий город. Каждый заказ = инфоповод = пост.

## 7. Тон голоса

**Живой, прямой, честный, анти-инфоцыганский. От ПЕРВОГО лица** (это сайт Сергея, Frogface — метафора, но говорит Серёжа).

✅ Канон-фразы: **«one love / одна любовь»** (завершающая), приветствия из канала «С лицом лягушки»: *«Здорово, мандиты / пираты / разбойники / мошенники»*. Темы: свобода, уверенность, уважение, быть собой.
✅ Экспертность — только кейсами, не словами. Терминология ресторанной сферы — где уместно (Босс реально шарит).
✅ Мат — по месту. В личных зонах/now/пасхалках можно. На B2B-страницах аккуратно/почти нет.
✅ Тон = смесь дневника (now/обновления) + манифеста (главная).

❌ Запрещено: «купите курс», «успешный успех», «упакуем смыслы», «выведем бизнес на новый уровень», «прокачай мышление», «трансформация», «комьюнити единомышленников», наставнический тон, пустая экспертность.

Голос-эталон: *«Я сделал бар. Я заебался делать афиши целыми днями — поэтому собрал контент-фабрику. Я работал в общепите почти 10 лет — поэтому делаю инструменты для ресторанов. Это мой путь, мои ошибки, мои продукты.»*

---

## 8. Эстетика, звук, анимации

**Стиль залочен** (есть консистентный Soul-ID персонаж + найденная стилистика). Не искать заново.
- Время — **вечер** (залипнуть, подвести итоги). Без смены дня/ночи в MVP.
- Палитра — вечернее болото, тёплый свет, фиолетовые ноты ок, закат, звёзды. **Болото НЕ грязное/унылое.**
- Шрифты: Playfair Display (display) + Geist (sans) + JetBrains Mono. (уже стоит)
- **Анимации обязательны, но деликатно** (Босс: «показать яйца AI-креатора»). Seedance 2 / топ-модели. Frogface дышит/печатает/пьёт кофе, окна мерцают, вода, NPC. НЕ перегружать.
- **Звук**: lo-fi / hip-hop ambient (Босс вырос на хип-хопе). Toggle, **НЕ autoplay**. Будущее: стримить что слушает сейчас.

**Главный антипаттерн: generic AI slop.** Сайт = легенда одного персонажа, авторская вселенная, а не «смотрите я тоже генерирую».

---

## 9. Антипаттерны (нельзя)

- generic AI slop / Pixar / Ghibli-тренд / корпоративная стерильность / «как у всех»
- инфоцыганские формулировки (см. §7)
- autoplay со звуком
- перегруз анимациями ради анимаций
- непонятная навигация («куда нажимать»)
- **пустота за вау-обложкой** — нажал на объект, а там ничего (главный облом)
- бесконечная стройка ради стройки (запускать быстро!)
- сухой корпоративный лендинг

## 10. Reality check + запуск

- Время: Босс готов по несколько часов в день. Проект зажигает.
- Формула: **быстро, но уже вау.** MVP за неделю (в идеале быстрее — «всё уже почти есть, собрать воедино»).
- **Mobile критичен** (вход из Telegram/соцсетей) + desktop раскрывает шире. Mobile не обрезок, но проще по управлению.
- Трафик: органика first — личные соцсети, аудитория Edison, история закрытия бара. Реклама позже.
- Пост запуска: *«Edison закрылся. Вы меня знаете. 14-15 лет делаю свои проекты, почти 10 лет строил Edison — теперь запускаю Frogface Studio / frogface.space. Мой новый мир, услуги, продукты, попытка выбраться из болота. Кому нужно — обращайтесь. Кому нет — позалипайте и напишите критику.»*

## 11. Личность Босса (для тона всех текстов)

- 14-15 лет предпринимательства, всегда самобытное/своё (первый ударный факт — даёт уважение)
- Глубоко в AI 3+ года, веб-кодинг/приложения ~1.5 года. Не энтузиаст — **предприниматель, внедряющий AI в реальный бизнес**
- Стык: предпринимательство + креатив + общепит + дизайн + музыка + AI
- Личность: **свобода, быть собой, делать своё — но по уму.** Не как все. Ироничный, живой, настоящий.
- Первый сюжет легенды: **путь из болота** (где я сейчас → куда смотрю → почему выберусь → что строю). Усталость не выпячивать.
- Честная часть: много ошибок/факапов на всех этапах — рассказать без героизации.

## 12. План фаз (MVP = ядро)

### Фаза 1 — Главный кадр + манифест + «В путь» (приоритет №1)
Hero-сцена (закат→звёзды, Frogface на лавочке, Башня вдали, текст, кнопка). Это «один час» Босса и 80% вау. Генерим финальный hero через Higgsfield.

### Фаза 2 — Карта болота (навигационный хаб)
Карта с 3 зданиями + Башней + туман войны. Клик → переход в локацию. Это НОВОЕ (не было).

### Фаза 3 — 3 локации
- Хижина: now-статус + биография (контент Босса) + галерея
- Edison: история + кейсы + соц-доказательство (фото-референсы от Босса)
- Studio: уже готов, привязать как здание + из меню

### Фаза 4 — Биография (контент-ядро)
Текст от первого лица: Новоленино → филфак → первый бизнес → дизайн → Edison 9.5 лет → музыка/фристайл → AI → Frogface Studio. Босс наговорит отдельно.

### Фаза 5 — Polish + mobile + звук-toggle + пост запуска

Расширение (после MVP): Receptor, магазин, кладбище факапов, спортзал, остальные здания, walk-анимация, калькулятор Studio, EN-версия, now→Telegram автопостинг.
