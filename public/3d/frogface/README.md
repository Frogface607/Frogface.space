# Frogface 3D Assets

Generated first-pass WebGL assets for the Frogface character.

## Files

- `frogface-base.glb`: neutral rig-master style base with body and boxer shorts.
- `frogface-present.glb`: base body plus present-day outfit.

## Groups

- `Frogface_Base`: body, head, eyes, hands, feet, spots, boxer shorts.
- `Frogface_Outfit_Present`: grey jeans layer.
- `Frogface_Accessories`: necklace chain and peace-sign pendant.

## Canon Notes

- The base body stays reusable for future outfits.
- Grey jeans are intentionally separate from the base boxer shorts.
- The peace pendant hangs from a chain around the neck and is not fused into the chest.
- This is a procedural blockout for browser/game integration. Blender sculpt polish can replace the mesh later while preserving group names.
